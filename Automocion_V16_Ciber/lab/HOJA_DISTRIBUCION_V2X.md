## 🚗 Tecnología V2X — Vehicle-to-Everything

**¿Qué es?** Vehículos que se comunican entre sí, con infraestructura, peatones y servicios.

**¿Por qué importa?** Mayor seguridad vial, pero... también riesgos de seguridad.

**¿Qué vamos a aprender?** Cómo funcionan, dónde fallan, cómo se protegen.

## 🔑 Conceptos Clave a Retener

| Concepto | Explicación |
|----------|-------------|
| **V2V** | Vehicle-to-Vehicle — coche con coche |
| **V2I** | Vehicle-to-Infrastructure — coche con semáforos |
| **V2P** | Vehicle-to-Pedestrian — coche con peatón |
| **V2N** | Vehicle-to-Network — coche con servidor |
| **DSRC** | Protocolo antiguo, radio directa (100 m) |
| **5G/C-V2X** | Protocolo nuevo, redes 5G (500 m) |
| **NB-IoT** | Protocolo Help Flash en España (bajo consumo) |
| **Tenga cuidado** | Datos en texto plano = **inseguro** |
| **CVE-2025-65855** | Vulnerabilidad Help Flash (real) |
| **250,000** | Dispositivos Help Flash afectados en España |

## ❓ Preguntas que Haremos

Prepárate para responder:

1. *¿Qué significa V2X?*  
   → Respuesta: Vehicle-to-Everything

2. *¿Cuál es la diferencia entre DSRC y C-V2X?*  
   → DSRC: radio privada (100m), C-V2X: redes 5G (500m)

3. *¿Qué es el mayor riesgo de Help Flash?*  
   → Datos en texto plano = localización expuesta

4. *¿Cómo se protege la comunicación?*  
   → Encriptación, autenticación, verificación, firma

5. *¿Cuántos Help Flash están afectados en España?*  
   → 250,000+
