💻 Komandoak Saio 1 (Kaptura)

1. SSH konektatzea Raspberry Pi-ra:

$ ssh pi@raspberrypi.local password: raspberry (defektua, aldatzea!)

2. RTL-SDR identifikatzea:

$ rtl_test -t Found 1 device(s): 0: Realtek, RTL2832U, SN: 00000001 Using device 0: Realtek RTL2832U Testing the test mode signal ...

3. Baseline kaptura (seinalerik gabe):

$ rtl_fm -f 433.92M -s 250k -g 49.6 \ - | sox -t raw -r 250k -e signed -b 16 -c 2 -V1 \ - baseline.iq8 stat

4. Mando seinalea kaptura (4 segundu):

$ timeout 4 rtl_fm -f 433.92M -s 250k -g 49.6 \ - | sox -t raw -r 250k -e signed -b 16 -c 2 -V1 \ - capture_001.iq8 (Mando sakatzea LEHENBIZIAN, orduan CTRL+C)

5. Fitxategiak baieztatzea:

$ ls -lh *.iq8 $ file baseline.iq8 $ wc -c capture_*.iq8

6. Fitxategiak transferitu (laptop-era):

$ scp pi@raspberrypi.local:*.iq8 ~/captures/
💡 Aholkua: Honako komandoak bash script batean jartzea praktikagarriagoa dute, "capture.sh" gisaren.

🐍 Python Script Nagusia

Fitxategia irakurri eta bistaratzea:

import numpy as np import matplotlib.pyplot as plt from scipy import signal # Fitxategia irakurri filename = "capture_001.iq8" iq_data = np.fromfile(filename, dtype=np.uint8) # I eta Q osagaiak banandu iq_data = iq_data.astype(np.float32) - 127.5 I = iq_data[::2] Q = iq_data[1::2] # Potentzia kalkulatu (dBm-an) power = 10 * np.log10(I**2 + Q**2 + 1e-10) # Denborea sekundutan sample_rate = 250000 # 250 kHz time = np.arange(len(I)) / sample_rate # Grafikak sortzea fig, axes = plt.subplots(2, 1, figsize=(12, 8)) # 1. Potentzia denboraz axes[0].plot(time, power, linewidth=0.5) axes[0].set_ylabel('Potentzia (dBm)') axes[0].set_title('Seinalaren Potentzia Denboraz') axes[0].grid(True, alpha=0.3) # 2. Espektroa (FFT) fft_result = np.abs(np.fft.fft(I + 1j*Q)) freq = np.fft.fftfreq(len(fft_result), 1/sample_rate) / 1e6 # MHz-an axes[1].plot(freq[:len(freq)//2], fft_result[:len(fft_result)//2]) axes[1].set_xlabel('Frekuentzia (MHz)') axes[1].set_ylabel('Amplitudea') axes[1].set_title('Espektroa (FFT)') axes[1].grid(True, alpha=0.3) plt.tight_layout() plt.savefig('analisis.pdf') plt.show()
✅ Emaitza: 2 grafikak (potentzia + espektroa) PDF-an

🔍 Gertaera Detektatzea (Python)

Mando sakatze momentua detektatzea:

# Zarata neurtzea (baseline aurrena) baseline_iq = np.fromfile("baseline.iq8", dtype=np.uint8).astype(np.float32) - 127.5 baseline_power = np.mean(baseline_iq**2) noise_threshold = baseline_power * 1.5 # 1.5x intelektua zarataren gainetik # Seinalea irakurri capture_iq = np.fromfile("capture_001.iq8", dtype=np.uint8).astype(np.float32) - 127.5 capture_power = capture_iq**2 # Gertaera detektatzea events = np.where(capture_power > noise_threshold)[0] if len(events) > 0: event_start = events[0] / sample_rate event_end = events[-1] / sample_rate event_duration = event_end - event_start print(f"Gertaera detektatua!") print(f"Hasiera: {event_start:.3f} s") print(f"Amaiera: {event_end:.3f} s") print(f"Iraupena: {event_duration:.3f} s") else: print("Gertaera ez detektatua") # JSON gordetzea (hurrengo ebaluazioa) import json results = { "filename": "capture_001.iq8", "event_start_s": float(event_start), "event_end_s": float(event_end), "duration_s": float(event_duration), "peak_power_dbm": float(np.max(10*np.log10(capture_power + 1e-10))), "noise_level_dbm": float(10*np.log10(baseline_power)) } with open("events.json", "w") as f: json.dump(results, f, indent=2)
💡 Emaitza: events.json fitxategi automatikoki gordeta, txosten azkenera berari jartzea.

📈 Grafikak Konparatu (Sakatze anitzak)

Nola konparatu captures artean:

import glob # Fitxategi guztiak irakurri capture_files = sorted(glob.glob("capture_*.iq8")) fig, axes = plt.subplots(len(capture_files), 1, figsize=(12, 4*len(capture_files))) for idx, filename in enumerate(capture_files): iq_data = np.fromfile(filename, dtype=np.uint8).astype(np.float32) - 127.5 power = 10 * np.log10(iq_data[::2]**2 + iq_data[1::2]**2 + 1e-10) time = np.arange(len(power)) / 250000 axes[idx].plot(time, power, linewidth=0.5, color='steelblue') axes[idx].set_ylabel('dBm') axes[idx].set_title(f'{filename} - Potentzia Denboraz') axes[idx].grid(True, alpha=0.3) plt.xlabel('Denbora (s)') plt.tight_layout() plt.savefig('konparazioa_captures.pdf') plt.show() print(f"✅ {len(capture_files)} capture konparatuta!")
